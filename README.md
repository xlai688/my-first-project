# 单词部落 · Word Tribe

《单词部落》是一个面向考研英语的原创卡通策略学习游戏 MVP。玩家通过学习单词、挑战迷雾守卫获得金币与经验，再升级自己的知识基地。

## 技术栈

- React 19 + TypeScript
- Vite 6
- lucide-react 图标
- 浏览器 `localStorage` 存档

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端输出的本地地址即可体验。生产构建：

```bash
npm run build
```

## 玩法

- **我的基地**：查看等级、金币、经验、连续学习天数，并点击地图建筑。
- **建筑升级**：基地只保留单词营和真题塔，两套经验与等级独立记录。
- **单词营**：浏览 60 个考研核心示例词汇、释义、例句和熟练度。
- **单词挑战**：显示英文并从四个中文释义中选择；答对获得奖励，答错进入重点复习。
- **重点复习**：集中练习战斗中答错的词汇。
- **成长记录**：按日期查看练习数量和累计成长。

所有进度（金币、等级、建筑、熟练度、重点复习和学习记录）会自动保存到当前浏览器的 `localStorage`。清除网站数据会重置存档。

## 完整词库与许可

词库包含 **5,530 条**社区整理的考研大纲相关词汇，替代原先 60 个示例词；全部词汇开放挑战和搜索，图鉴每页显示 24 条，单词营预览前 24 条。挑战优先抽取未学习、低熟练度及曾答错词汇。旧版 `word-tribe-v1` 存档仍按英文单词关联，不重置金币、经验、建筑或学习记录。

数据来源：[exam-data/NETEMVocabulary](https://github.com/exam-data/NETEMVocabulary)，文件 [netem_full_list.json](https://github.com/exam-data/NETEMVocabulary/blob/master/netem_full_list.json)。上游说明其词表依据 2024 年英语（一）大纲整理，释义经初步校对；这是社区整理数据，不是本项目自行发布的官方词表。

词库数据及其改编遵循 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)：署名、非商业使用、相同方式共享。原始数据保存于 `src/data/netem_full_list.json`；`src/words.ts` 将中文字段映射到游戏字段，保留序号、词频、其他拼写、分类及子分类。源数据没有词性和例句，这些字段留空。游戏熟练度、学习状态和答题次数来自个人存档，与静态词条分离。商业用途需另行取得相应授权。


## 学习模式范围

当前学习内容严格收敛为两种：**单词挑战**（英文单词选择唯一中文释义）和**历年考研真题阅读**（按年份、英语一/二、Text、题号组织真实材料）。项目已导入用户提供的 2017—2025 英语（一）Part A 原文与题目；附件未提供可可靠确认的答案/解析，因此显示“答案/解析数据待补充”，不会伪造模拟题。词库、错词记录、学习进度和基地仅作为辅助反馈。已移除英译中输入、中译英、拼写、听力、配对、模拟阅读及自动生成阅读题。


## 用户提供资料导入记录

- 单词营：从用户上传的《考研英语5500词（乱序版）》DOCX 实际解析 **5,493 个去重词条**，字段包括单词、音标、释义和备注。DOCX 实际可解析条目少于文件名所称 5,500，未补造缺失词条。
- 真题塔：从用户上传的 2017—2025 英语（一）PDF 提取 Section II Reading Comprehension Part A，共 9 年 × 4 个 Text；2018 Text 4 仅提取到 4 道题，标记为 `needs_review`，其余 Text 提取 5 道题。文章和题目保存在 `src/data/readings.json`。
- 附件中没有可可靠确认的标准答案/解析，因此所有题目答案为 null，界面显示“答案/解析数据待补充”；没有 AI 猜答案。PDF 中的乱码、断字或选项错位未修正，需人工复核的内容由 `parseStatus` 标记。
