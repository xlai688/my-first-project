# 单词部落 · Word Tribe

《单词部落》是一个面向考研英语的原创卡通策略学习游戏 MVP。玩家通过学习单词、挑战迷雾守卫获得金币与经验，再升级自己的知识基地。

## 技术栈

- React 19 + TypeScript
- Vite 6
- lucide-react 图标
- 浏览器 `localStorage` 存档

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端输出的本地地址即可体验。生产构建：

```bash
npm run build
```

## 玩法

- **我的基地**：查看等级、金币、经验、连续学习天数，并点击地图建筑。
- **建筑升级**：主城、单词营、复习塔、训练营、阅读大厅均可使用金币升级；主城升级解锁更多词汇，主城 2 级开放阅读大厅。
- **单词营**：浏览 60 个考研核心示例词汇、释义、例句和熟练度。
- **单词战斗**：随机进行英译中、中译英、四选一。答对造成伤害并获得 +20 金币 / +15 XP，答错会反击并加入重点复习。
- **重点复习**：集中练习战斗中答错的词汇。
- **成长记录**：按日期查看练习数量和累计成长。

所有进度（金币、等级、建筑、熟练度、重点复习和学习记录）会自动保存到当前浏览器的 `localStorage`。清除网站数据会重置存档。
